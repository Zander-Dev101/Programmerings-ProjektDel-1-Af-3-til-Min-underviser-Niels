# Type Members

Loesningen er delt i to konsolapps:

- `TypeMembers.Part1`: bruger en DTO (`PensionResult`) som returtype.
- `TypeMembers.Part2`: bruger en anonymous type som returdata.

Koer del 1:

```bash
dotnet run --project TypeMembers.Part1
```

Koer del 2:

```bash
dotnet run --project TypeMembers.Part2
```

Eksempel paa input:

```text
16-04-1962
```
